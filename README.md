# Cyber Swiss Army Knife
This Python program enables you to easily perform some activities useful in cyber security field.

## Current Features
- encoding and decoding using [common](./modules/encode.py) encodings
- hashing and hash cracking using a wordlist
- manually customising and sending a web request from the terminal

## Prerequisites
Python 3.10 or newer

## Installation
Simply clone the repository and run the program with 
```
python3 main.py
```

## Possible Upcoming Features
- packet sniffing
